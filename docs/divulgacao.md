# Divulgação do app (sem custo)

Link base da loja:
`https://play.google.com/store/apps/details?id=com.porzelt.ntsemanuncios`

Cada mensagem abaixo usa um link com uma **origem própria** (`utm_source`), para
a Play Console mostrar de onde vêm as instalações (Aumentar número de usuários →
Desempenho na loja). Se a origem não aparecer lá, o link continua funcionando.

| Onde usar | Origem no link |
|---|---|
| Família | `familia` |
| Igreja / grupo da igreja | `igreja` |
| Jovens / estudo bíblico | `jovens` |
| Pedido a pastores e líderes | `lider` |
| Instagram / Facebook | `redes` |
| Cartaz / QR code | `qrcode` |
| Botão "Compartilhar o app" dentro do app | `convite` |
| Versículo compartilhado | `versiculo` |

Regras de ouro: uma mensagem por grupo (sem repetir), respeitar as regras do
grupo, nunca pedir avaliação em troca de nada, nunca avaliações falsas.

## 6. Cartaz com QR code

Arquivos em `assets/divulgacao/`:
- `cartaz-qr-1080x1350.png`: cartaz pronto (status do WhatsApp, Instagram, mural
  da igreja). Tamanho bom também para imprimir em A5 ou A4.
- `qr-loja.png`: só o QR code (1024 px), para colocar em outros materiais.

Os dois apontam para o link com `utm_source=qrcode` (conferido: decodificam
certo). Para imprimir, deixe uma margem branca de pelo menos 1 cm ao redor do QR.
